# Templates — use only when useful

Minimum for any project: Charter, Plan, Task/Checkpoint, QA/evidence proportional to deliverable. For software: Product Map, Architecture Map and Feature/Flow/Release gates as scope requires. For larger/high-risk projects: add registers below when they prevent real omissions.

These are **optional frameworks**, not an instruction to create 30 blank files. Once a record exists, give it a stable ID, owner, updated date, status and source evidence. Routine corrections need not trigger an ADR or change request.
