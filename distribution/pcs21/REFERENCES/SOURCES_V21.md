# Nguồn được đối chiếu cho PCS 2.1 (31/10/2026)

Các nguồn dưới đây cung cấp cơ sở kỹ thuật hoặc định hướng, không có nghĩa PCS được nhà cung cấp chứng nhận.

- Claude Code memory/CLAUDE.md: https://code.claude.com/docs/en/memory
- Claude Code Skills: https://code.claude.com/docs/en/skills
- Codex AGENTS.md: https://developers.openai.com/codex/guides/agents-md
- OpenAI prompt/skills rethink (2026): https://developers.openai.com/blog/rethinking-skills-and-prompts-for-gpt-6-astra
- Cursor Rules: https://docs.cursor.com/context/rules-for-ai
- Google Antigravity IDE Customizations/Rules: https://codelabs.developers.google.com/getting-started-agy-ide
- Google Antigravity Skills: https://codelabs.developers.google.com/getting-started-with-antigravity-skills
- OpenAI Agent Skills: https://developers.openai.com/plugins/build/skills
- GitHub Spec Kit: https://github.com/github/spec-kit
- ISO/IEC/IEEE 29148:2018, yêu cầu hệ thống/phần mềm (bản 2026 mới ở dạng dự thảo): https://www.iso.org/standard/72089.html
- NIST SSDF SP 800-218 v1.1: https://csrc.nist.gov/pubs/sp/800/218/final
- OWASP AI Agent Security: https://cheatsheetseries.owasp.org/cheatsheets/AI_Agent_Security_Cheat_Sheet.html

**Lưu ý nguồn thay đổi theo thời gian:** đường dẫn và cách nạp user/global rules có thể được hãng thay đổi sau ngày lập bộ PCS 2.1. Xác nhận lại ở thời điểm triển khai môi trường cụ thể.
