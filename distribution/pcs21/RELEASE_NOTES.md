# Release notes — PCS 2.1.0

**Purpose:** turn the manual per-project starter experience of PCS 2.0 into user-level, agent-triggered project bootstrap from SRS/outline/idea, while preserving the existing verified task/feature/flow/release/moment engine.

## New
- `install-agent` with idempotent managed rules and Skills for Claude, Codex, Antigravity; Cursor User Rules snippet for UI.
- `bootstrap --source --project [--adopt]`, safe source intake, SHA-256, private extraction, project scaffolding and initial moment.
- Readable playbook and 9 practical guides on one-prompt workflow, architecture/impact, user approvals, QA, existing-project migration and real-vendor assurance.
- Regression tests for installation, source extraction, conflict/no-overwrite, privacy, first moment and continuity.

## Carried forward
- PCS 2.0 state schemas, local CLI, full moment snapshots, history preview and 31 tests.
- Source of truth, cross-module quality and release safety concepts; no token limit or agent proliferation mandate.

## No claims made
- No production/IAICT deploy; no vendor-certified Claude/Codex/Cursor/Antigravity E2E; no private app login; no full app generated automatically from SRS **without a coding agent**.
